# SerialCraft 0.4.6-beta

**Minecraft Java 26.2 · Fabric · Java 25**

## What's new

- Stream game telemetry to your board from the **Events** tab: health, hunger, world time, and events such as damage or death.
- New **Visualizer** tab with a timeline, Sensor view, and waveform generator on a dedicated channel.
- Board identification through USB descriptors, firmware announcements, and supported banners. Generic USB adapters are no longer presented as a confirmed board model.
- Remembered Wi-Fi pairing through HMAC challenge-response, with an option to forget a board.
- Updated **Home** panel with connection details, console, and baud rate changes through **Apply and reconnect**.
- The Hardware I/O Module editor now has **Configuration** and **Diagnostics** tabs, contextual **?** help, and server confirmation when saving.

## Fixes

- Received samples, redstone readings, logic results, and emitted signals are tracked separately. OR, AND, and XOR now combine their inputs correctly.
- Samples received while an input condition is closed are retained until it opens again.
- Stable TX values are resent after reconnection and USB startup; RX samples are invalidated when the session changes.
- Per-channel stops retain up to 64 distinct shutdown commands without dropping other accepted stops.
- The generator keeps its channel fixed for each run. Stopping cancels pending values and requests zero on the original channel. An older run cannot send commands into a new connection session.
- More robust verified USB connections, session shutdown, and Wi-Fi handshakes; visible Wi-Fi server startup errors; corrected welcome text in all four locales.

## Compatibility and upgrading

- **Update clients and servers together**: internal Hardware I/O Module packets use new identifiers.
- Persisted block/entity identifiers, recipes, and compatible configuration are preserved. Review invalid legacy channels and circuits that relied on the previous AND/XOR behavior.
- The hardware protocol still uses newline-terminated `channel:0..255` messages. USB defaults to **115200 baud**, which must match your firmware.
- Example sketches send the first sample, including zero, then changes and periodic snapshots so RX recovers when modules are reloaded.
- Requires **Fabric API** for Minecraft 26.2.

## Documentation and scope

- Guides, protocol references, and tutorials in Spanish and English, with slots prepared for real photographs and videos.
- Each player connects hardware through their own client. TCP operates on a local network and remains unencrypted.
- TX writes are not acknowledgements of physical execution. Queues are bounded and do not guarantee every pulse under overload.
