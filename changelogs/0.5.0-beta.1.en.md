# SerialCraft v0.5.0 Beta — 0.5.0-beta.1

**Minecraft Java 26.2 · Fabric Loader 0.19.3+ · Fabric API · Java 25+**

This beta brings the interface work developed on `test` and the community's Simplified Chinese translation into one release. SerialCraft connects Arduino, ESP32, Raspberry Pi and other serial or TCP devices with Minecraft through bidirectional hardware signals and game telemetry.

> **Pre-release:** this is a Beta, not a stable release. Back up worlds before upgrading and update the mod on clients and servers together. Graphical UI inspection and tests with physical USB/Wi-Fi boards remain manual checks; automated tests do not certify every hardware setup.

## Interface and user experience

- **Horizontal navigation:** Home and Boards appear to the left of the original centered SerialCraft logo; Events and Visualize appear to the right. The existing icon atlas, page accents and translucent visual identity are preserved.
- **Home:** the connected-device card keeps its randomly selected cat sprite. Connection properties scroll independently, while the bidirectional terminal remains in its own column so messages and command controls stay accessible.
- **Welcome:** the connection screen uses vertically centered translucent panels, USB and Wi-Fi method cards, clearer spacing and a separate notice for remembered boards. Connection help and pairing controls remain available.
- **Shared controls:** glass headers, borders, button padding, margins and text alignment are consistent across the panel. Navigation and IO editor layout adapt to the available GUI space.
- **Boards, Events, Visualize and the IO module editor:** retain their existing functionality with the updated panel styling, including configuration, diagnostics and contextual help. The logo, icons, cat atlas and existing assets are carried forward without a new redesign.

## Simplified Chinese — 简体中文

- Adds `zh_cn.json`, originally contributed by [@SK-Xiaohan](https://github.com/SK-Xiaohan) in [PR #4](https://github.com/LeonardoAliaga/SerialCraft/pull/4).
- Includes the proposed Chinese name **串连世界**, alongside the SerialCraft identity. Thank you for helping connect Minecraft and real-world electronics with the Chinese-speaking community!
- Covers Welcome, Home, navigation, Boards, Events, Visualize, the IO editor, help dialogs, connection messages and dynamic device states.
- Completes the new Home properties label introduced on `test` and keeps the terminal's `TX`, `RX` and `TM` prefixes recognizable in Chinese help text. All five locale files contain the same 402 translation keys and compatible Minecraft format arguments.
- Preserves the contributor's original commit and authorship through a merge into `test`; credits are also included in the mod metadata and README.

## Release and technical checks

- Uses the Semantic Versioning identifier `0.5.0-beta.1`, propagated from Gradle into the Fabric metadata and JAR filename.
- Adds automated checks for duplicate localization keys, UTF-8/Unicode, missing translations, format arguments, literal and dynamic UI keys, archive integrity and packaged UI assets.
- Keeps Minecraft 26.2, Java 25, Fabric Loader/API and Gradle versions unchanged. Hardware channels, saved block IDs and networking behavior are preserved.
- Publishes the verified JAR as a **GitHub Pre-release**, with English release notes. Modrinth publication and description updates require an explicit manual opt-in; this release does not publish to other marketplaces.

## Download and test

Install `serialcraft-0.5.0-beta.1.jar` together with Fabric API for Minecraft 26.2. In Minecraft, select **简体中文（中国大陆）** in Language settings to use the Chinese UI.

For source testing in IntelliJ IDEA, check out tag `v0.5.0-beta.1`, select JDK 25 as the project and Gradle JVM, import the Gradle project, then run `build` and `runClient`. Inspect all pages, scroll areas, tooltips and IO editor sections at several GUI scales; verify USB and Wi-Fi using a physical board.
