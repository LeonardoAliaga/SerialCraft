# SerialCraft 0.5.1 Beta — Visual identity

**Minecraft Java 26.2 · Fabric Loader 0.19.3+ · Fabric API · Java 25+**

## Changes

- Replaces `textures/gui/logo-txt.png` with the new SerialCraft image supplied by Leonardo Aliaga. The header no longer displays the previous composition containing the Arduino and Minecraft logos.
- Updates navigation rendering to the PNG's actual **1038 × 446** dimensions, preserving its aspect ratio, transparency and centered placement.
- Updates the version, README and Modrinth description. GitHub release notes are published in Spanish and Modrinth notes in English.
- Records a review of graphics in the mod, website and public Modrinth listing in the [image and trademark audit](https://github.com/LeonardoAliaga/SerialCraft/blob/v0.5.1-beta/maintenance/asset-audit-0.5.1-beta.md) (Spanish).

Documentation updates since 0.5.0 also include fixes for canonical URLs, indexing, historical routes and language switching, together with the English digital/analog and troubleshooting guides.

## Scope

This update replaces the header logo. Other textures and screenshots still contain the previous branding and are identified in the audit; this release does not certify rights to all images. The resemblance of the new infinity symbol and other branding assets also needs review.

Compatibility with 0.5.0-beta is preserved, including saved worlds, hardware channels and all five locales. USB/Wi-Fi communication and block logic are unchanged.

Install `serialcraft-0.5.1-beta.jar` alongside Fabric API for Minecraft 26.2. This version remains a **Beta**.
