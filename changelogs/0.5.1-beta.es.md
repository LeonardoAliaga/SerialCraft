# SerialCraft 0.5.1 Beta — Identidad visual

**Minecraft Java 26.2 · Fabric Loader 0.19.3+ · Fabric API · Java 25+**

## Cambios

- Reemplaza `textures/gui/logo-txt.png` por la nueva imagen de SerialCraft proporcionada por Leonardo Aliaga. El encabezado deja de mostrar la composición anterior con los logotipos de Arduino y Minecraft.
- Ajusta el renderizado de la barra de navegación a las dimensiones reales del nuevo PNG, **1038 × 446**, para conservar su proporción, transparencia y centrado.
- Actualiza la versión, el README y la descripción de Modrinth. Las notas de GitHub se publican en español y las de Modrinth en inglés.
- Documenta una revisión de los recursos gráficos del mod, la web y la ficha pública de Modrinth en el [informe de imágenes y marcas](https://github.com/LeonardoAliaga/SerialCraft/blob/v0.5.1-beta/maintenance/asset-audit-0.5.1-beta.md).

La documentación acumulada desde 0.5.0 también incorpora correcciones de URL canónicas, indexación, rutas históricas y cambio de idioma, además de las guías inglesas de señales digitales/analógicas y resolución de problemas.

## Alcance de la actualización

Este cambio sustituye el logo del encabezado. Otras texturas y capturas todavía contienen la identidad anterior y están identificadas en el informe; esta versión no constituye una certificación de derechos sobre todas las imágenes. La similitud del nuevo infinito y de otros recursos de marca también requiere revisión.

Se conserva la compatibilidad de 0.5.0-beta, incluidos los mundos, canales de hardware y cinco idiomas. No se modifica la comunicación USB/Wi-Fi ni la lógica de los bloques.

Instala `serialcraft-0.5.1-beta.jar` junto con Fabric API para Minecraft 26.2. Esta versión sigue siendo **Beta**.
