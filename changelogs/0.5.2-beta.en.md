# SerialCraft 0.5.2 Beta — Refreshed logos and Welcome screen fix

**Minecraft Java 26.2 · Fabric Loader 0.19.3+ · Fabric API · Java 25+**

## Changes

- Includes Leonardo Aliaga's logo redesign: a jumper-cable infinity symbol in the interface header, Laptop screen texture, Hardware I/O Module texture, and mod icon.
- Replaces the previous compositions containing the explicit Arduino and Minecraft logos in the two main model textures. Also includes the model and detail-texture updates supplied with the redesign.
- Fixes the logo aspect ratio on the Welcome screen (`WelcomePage`): uses the PNG's actual **1038 × 446** dimensions instead of **779 × 261**. Header height and the content below it follow the correct proportions, preserving centering and scrolling.
- Updates the README and Modrinth description, with Spanish release notes on GitHub and English notes on Modrinth.

The updated [image review](https://github.com/LeonardoAliaga/SerialCraft/blob/v0.5.2-beta/maintenance/asset-audit-0.5.2-beta.md) (Spanish) distinguishes this release's replacements from remaining screenshots, website assets, and legacy textures.

Minecraft 26.2, Java 25, all five locales, and USB/Wi-Fi communication behavior are preserved.

Install `serialcraft-0.5.2-beta.jar` alongside Fabric API for Minecraft 26.2. This version remains a **Beta**.
