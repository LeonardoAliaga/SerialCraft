# SerialCraft 0.5.2 Beta — Logos renovados y bienvenida corregida

**Minecraft Java 26.2 · Fabric Loader 0.19.3+ · Fabric API · Java 25+**

## Cambios

- Incorpora el rediseño de logos de Leonardo Aliaga: infinito formado por cables jumper en el encabezado, la pantalla de la Laptop, la textura del módulo de E/S y el icono del mod.
- Sustituye las composiciones anteriores con los logotipos explícitos de Arduino y Minecraft en las dos texturas principales de los modelos. Actualiza también los modelos y la textura de detalle incluidos en el rediseño.
- Corrige la proporción del logo en la bienvenida (`WelcomePage`): utiliza las dimensiones reales del PNG, **1038 × 446**, en lugar de **779 × 261**. La altura del encabezado y el contenido inferior se ajustan a la proporción correcta, conservando el centrado y el desplazamiento.
- Actualiza el README y la descripción de Modrinth, con notas de versión en español para GitHub y en inglés para Modrinth.

La [revisión de imágenes actualizada](https://github.com/LeonardoAliaga/SerialCraft/blob/v0.5.2-beta/maintenance/asset-audit-0.5.2-beta.md) distingue las sustituciones de esta versión de las capturas, recursos web y texturas históricas todavía pendientes.

Se mantienen Minecraft 26.2, Java 25, los cinco idiomas y el comportamiento de comunicación USB/Wi-Fi.

Instala `serialcraft-0.5.2-beta.jar` junto con Fabric API para Minecraft 26.2. Esta versión sigue siendo **Beta**.
