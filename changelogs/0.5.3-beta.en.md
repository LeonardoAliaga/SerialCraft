# SerialCraft 0.5.3-beta — NeoForge support and output settings

SerialCraft now supports NeoForge alongside Fabric on Minecraft 26.2 and Java 25, sharing its hardware protocol, interface and gameplay logic.

## What's new

- Separate installable Fabric and NeoForge JARs with loader-specific metadata and bundled USB/Wi-Fi libraries.
- A settings page accessible from the top-right gear, even before connecting a board.
- On connection: send zero, send a custom value, or restore the last saved value for the current world, device and channel.
- On normal disconnection: send zero, send a custom value, or leave the last state without sending a final message.
- Independent startup and shutdown policies, custom integer values from 0 to 255, and confirmation before discarding unsaved settings.
- Updated documentation and project description, retaining the latest images from the Modrinth page.

## Installation

- Minecraft Java 26.2 and Java 25 or newer.
- This NeoForge build requires NeoForge 26.2.0.93 or newer for Minecraft 26.2. Fabric API is not required.
- The separate Fabric build requires Fabric Loader 0.19.3 or newer and Fabric API for 26.2.
- Install the JAR for your loader and update clients and server together. Mixed-loader multiplayer has not been validated.

Output settings apply to Minecraft-to-hardware I/O channels. Abrupt crashes or unplugged cables cannot deliver a final value. This remains a beta release; graphical inspection and physical USB/Wi-Fi board checks remain manual tests.
