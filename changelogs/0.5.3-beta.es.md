# SerialCraft 0.5.3-beta — Fabric y NeoForge

SerialCraft incorpora NeoForge para Minecraft 26.2 y Java 25, manteniendo Fabric y compartiendo la lógica de placas, señales e interfaz.

## Novedades

- Dos archivos instalables: `serialcraft-fabric-0.5.3-beta.jar` y `serialcraft-neoforge-0.5.3-beta.jar`.
- Nueva página de configuración desde el engranaje superior derecho, disponible antes de conectar una placa.
- Al conectar: enviar cero, enviar un valor personalizado o restaurar el último valor guardado para el mundo, dispositivo y canal.
- Al desconectar normalmente: enviar cero, enviar un valor personalizado o conservar el estado sin enviar un mensaje final.
- Políticas de inicio y cierre independientes, con valores personalizados de 0 a 255 y confirmación al salir con cambios sin guardar.
- README, descripción inglesa de Modrinth y guía de desarrollo actualizados, conservando las imágenes recientes de la página de Modrinth.

## Instalación

- Minecraft Java 26.2 y Java 25 o superior.
- Fabric: Fabric Loader 0.19.3 o superior y Fabric API para 26.2.
- NeoForge: NeoForge 26.2.0.93 o superior para Minecraft 26.2; no requiere Fabric API.
- Elige el JAR de tu loader y actualiza clientes y servidor juntos. La conexión entre loaders diferentes no se ha validado.

Los ajustes afectan a canales de E/S de Minecraft hacia el hardware. Los cierres forzados o un cable desconectado no permiten garantizar un mensaje final. Esta versión continúa en beta; las pruebas visuales y con placas físicas siguen siendo comprobaciones manuales.
