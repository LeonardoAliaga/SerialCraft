# Acerca de SerialCraft

**SerialCraft** explora una pregunta sencilla: *¿qué sucede si los circuitos que construyes en Minecraft pueden comunicarse con componentes electrónicos reales?*

Es un proyecto de software abierto que conecta Minecraft Java (Fabric) con dispositivos externos mediante comunicación USB serial y, para placas compatibles, conexiones TCP dentro de una red local.

## Por qué existe

Minecraft ofrece un entorno accesible para experimentar con lógica de redstone. Los microcontroladores permiten leer sensores físicos y controlar salidas eléctricas de baja potencia. SerialCraft intenta unir ambos entornos para crear proyectos de aprendizaje en programación, electrónica y comunicaciones.

Su creador, **Leonardo Aliaga**, desarrolla el proyecto como parte de su interés en el software, el hardware y las telecomunicaciones. El código, el historial de cambios y los reportes públicos están disponibles en [GitHub](https://github.com/LeonardoAliaga/SerialCraft).

## Qué no promete el proyecto

SerialCraft se distribuye como software en desarrollo. No es un controlador industrial ni una solución para sistemas críticos. La compatibilidad, la seguridad de una conexión y el comportamiento de un circuito dependen también del firmware y del montaje físico.

Esta web distingue las características de la **versión de desarrollo 0.4.6-beta** del trabajo experimental en otras ramas. No se publican resultados de pruebas físicas que no se hayan realizado.

## Cómo participar

Puedes revisar el [código fuente](https://github.com/LeonardoAliaga/SerialCraft), [comunicar errores o sugerencias](https://github.com/LeonardoAliaga/SerialCraft/issues) y compartir qué montaje te gustaría aprender a realizar.

La documentación busca ser comprensible tanto para estudiantes como para desarrolladores con experiencia. [Contacta con el proyecto](/contacto) si tienes una consulta sobre estas guías.

SerialCraft es un proyecto independiente y no está afiliado a Mojang, Microsoft ni a los fabricantes de las placas mencionadas.
