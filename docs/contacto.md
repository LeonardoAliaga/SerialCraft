# Contacto y comunidad

¿Encontraste un fallo al conectar una placa, tienes una sugerencia para la documentación o quieres compartir un circuito? Estas son las vías públicas disponibles para contactar con el proyecto:

- **Errores y mejoras técnicas:** [GitHub Issues de SerialCraft](https://github.com/LeonardoAliaga/SerialCraft/issues). Es la mejor opción si otras personas también podrían beneficiarse de la respuesta.
- **Código y contribuciones:** [Repositorio en GitHub](https://github.com/LeonardoAliaga/SerialCraft).
- **Actualizaciones y contacto social:** [Instagram del creador](https://www.instagram.com/aliaga1924/).

## Cómo enviar una incidencia útil

Incluye la versión de Minecraft y del mod, el modelo de placa, USB o Wi-Fi, pasos concretos y lo que esperabas que ocurriera. Si adjuntas registros de consola, **borra primero tokens, contraseñas, IP públicas y cualquier dato personal**.

No publiques consultas privadas ni datos sensibles en GitHub Issues: los reportes son públicos. Para solicitudes relacionadas con la privacidad, utiliza un canal privado indicado en el perfil o las redes del creador; no envíes información personal por un issue.

## Antes de escribir

Muchas preguntas frecuentes se responden en [Solución de errores](/tutoriales/solucionar-errores), [Guía de instalación](/guide) y [Ejemplos](/ejemplos/).

Este sitio es la documentación de un proyecto independiente; no ofrece asistencia comercial garantizada ni tiempos de respuesta fijos.
