# Activación de publicidad y comprobaciones de publicación

La web usa la metaetiqueta `google-adsense-account` para verificación. Se conserva ads.txt. No se carga adsbygoogle.js: Analytics es opcional y su banner NO es una CMP publicitaria certificada.

Antes de activar publicidad:

1. En AdSense → Privacidad y mensajes → Normativas europeas, crear y publicar un mensaje para serialcraft.xyz con la CMP de Google. Indicar https://serialcraft.xyz/privacidad.html y los idiomas publicados. Ofrecer las opciones de consentimiento exigidas por Google.
2. Seguir la integración que genere AdSense para esta cuenta. Comprobar el comportamiento para visitantes del EEE, Reino Unido y Suiza y la reapertura del mensaje para retirar consentimiento. No habilitar anuncios con el botón de analítica de esta web.
3. Mantener el consentimiento de Analytics independiente o sustituir su aviso por una integración comprobada con la CMP; no tener dos mecanismos contradictorios.
4. Revisar los ajustes regionales aplicables, proveedores y exclusiones de anuncios automáticos (404, navegación sin contenido y documentos internos).
5. Solo después de comprobarlo, añadir el script oficial de AdSense. Actualizar ambas políticas de privacidad y el aviso para describir el comportamiento real. Verificar HTTPS, ads.txt y el estado del sitio en AdSense.

Search Console: enviar https://serialcraft.xyz/sitemap.xml, inspeccionar /guide.html y la canónica de /versiones/en/v0.3.6/guide.html. Las variantes HTTP y www deben redirigir al dominio HTTPS sin www. No solicitar indexación de los orígenes de esas redirecciones.
